# E2Eテスト用音声フィクスチャ

このディレクトリに置く WAV ファイルは実際の声を含むため `.gitignore` でコミット対象外にしている。E2E テストを実行する開発者が各自で用意すること。

## 録音方法

`arecord` で 16kHz/16bit/mono の WAV を直接録音できる。

```bash
arecord -f S16_LE -r 16000 -c 1 -d <秒数> tests/e2e/fixtures/audio/<ファイル名>.wav
```

## 必要なファイル

| ファイル名 | 長さ目安 | 内容 |
|---|---|---|
| `01_normal_speech.wav` | 12秒 | 「今日の会議の議事録をまとめました。よろしくお願いします。」と話した後、そのまま黙って録音終了まで待つ |
| `02_multiple_utterances.wav` | 6秒 | 「明日の予定を確認します。」→0.5秒程度の短い間→「会議は午後からです。」と続けて話す(長い間を置かない) |
| `03_silence_only.wav` | 12秒 | 何も話さず、部屋の環境音だけで録音する |
| `04_short_utterance.wav` | 7秒 | 「はい」または「テスト」など一言だけ話し、その後は黙って待つ |
| `05_toggle_recording.wav` | 4秒 | 「これはトグル動作の確認です。」と話す(末尾の無音は不要) |

## 用途

- `01`: 発話検知 + 無音タイムアウトでの自動停止(正常系)
- `02`: 短いポーズで誤ってタイムアウトしないこと、複数セグメント認識(正常系)
- `03`: VADが誤って発話と判定しないこと(異常系/誤検知なし確認)
- `04`: 極短い発話でもVAD/STTが機能すること(正常系)
- `05`: ブラウザE2Eでの録音→トグル停止操作の確認用

## 声に関する注意

自分の声を含む音声ファイルは、リポジトリを将来公開する可能性を考慮して絶対にコミットしないこと。CI等で自動化する場合は、TTS合成音声(espeak-ng等)や、ライセンスが明確な公開音声コーパスへの差し替えを検討する。
